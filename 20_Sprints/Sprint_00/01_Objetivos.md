# Sprint 00 — Objetivos

**Proyecto:** AccessWay  
**Estado:** Finalizado  
**Última revisión:** 23/09/2026

---

## 1. Objetivo del sprint

Definir las bases de AccessWay antes de comenzar su implementación.

Este sprint se centra en comprender el problema que pretende resolver la aplicación, identificar a sus usuarios, establecer los objetivos generales y delimitar el alcance inicial del proyecto.

## 2. Objetivos específicos

- Identificar el problema de accesibilidad que abordará AccessWay.
- Definir el público al que se dirige la aplicación.
- Establecer el objetivo general del proyecto.
- Definir los objetivos específicos.
- Identificar las funcionalidades principales.
- Delimitar un producto mínimo viable (MVP).
- Identificar posibles ampliaciones futuras.
- Establecer una organización inicial para el desarrollo.
- Comenzar la documentación del proyecto.

## 3. Resultado esperado

Disponer de una definición suficientemente clara del proyecto para comenzar a investigar las tecnologías necesarias y organizar las primeras tareas de implementación.

## 4. Criterios de finalización

El Sprint 0 se considera completado cuando están definidos:

- El problema que aborda AccessWay.
- Los usuarios a los que se dirige.
- Los objetivos del proyecto.
- El alcance inicial.
- Las funcionalidades previstas para el MVP.
- Las posibles ampliaciones futuras.
- La estructura inicial de documentación.
