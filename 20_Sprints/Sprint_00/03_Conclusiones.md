# Sprint 00 — Conclusiones

**Proyecto:** AccessWay  
**Estado:** Finalizado  
**Última revisión:** 23/09/2026

---

## 1. Resultado general

El Sprint 0 permitió establecer las bases conceptuales y organizativas de AccessWay.

Se definió el problema que pretende abordar la aplicación, el público al que se dirige y sus objetivos principales.

También se estableció la necesidad de desarrollar el proyecto de forma progresiva.

## 2. Principales aprendizajes

### Importancia de definir el problema

Antes de seleccionar tecnologías o comenzar a programar, resulta necesario comprender qué necesidad pretende resolver la aplicación.

En AccessWay, esta necesidad está relacionada con las dificultades que encuentran las personas con movilidad reducida durante sus desplazamientos.

### Importancia de delimitar el alcance

Se identificaron numerosas funcionalidades posibles.

Sin embargo, intentar desarrollarlas todas simultáneamente aumentaría la complejidad del proyecto.

Por ello, se decidió trabajar mediante un MVP y abordar las ampliaciones progresivamente.

### Importancia de la documentación

Se estableció una estructura documental que permitirá registrar tanto el resultado final como el proceso de desarrollo.

La documentación deberá mantenerse actualizada conforme avance el proyecto.

## 3. Decisiones principales

- Desarrollar AccessWay como aplicación orientada a la movilidad accesible.
- Incorporar un componente colaborativo mediante incidencias.
- Organizar el desarrollo de forma progresiva.
- Delimitar un MVP.
- Mantener separadas las funcionalidades iniciales y las posibles ampliaciones.
- Documentar las decisiones y el desarrollo real.

## 4. Aspectos pendientes al finalizar el sprint

La finalización del Sprint 0 no supone que AccessWay esté implementado.

Tras esta fase quedan pendientes:

- Profundizar en el estudio tecnológico.
- Configurar el entorno de desarrollo.
- Implementar el backend.
- Desarrollar las funcionalidades del MVP.
- Realizar las pruebas correspondientes.

## 5. Conclusión

El Sprint 0 proporcionó una base inicial para comenzar el desarrollo de AccessWay con objetivos definidos y un alcance organizado.

Las siguientes fases deberán transformar esta definición conceptual en una aplicación funcional.
