# Sprint 00 — Versión del proyecto

**Proyecto:** AccessWay  
**Estado del sprint:** Finalizado  
**Última revisión:** 23/09/2026

---

## 1. Identificación de la fase

**Fase:** Sprint 0  
**Tipo:** Definición y planificación inicial  
**Estado:** Completada

## 2. Resultado

El resultado de esta fase es la definición conceptual y organizativa inicial de AccessWay.

Se han establecido:

- El problema que aborda el proyecto.
- Los usuarios a los que se dirige.
- Los objetivos generales y específicos.
- El alcance inicial.
- Las funcionalidades contempladas.
- Las posibles ampliaciones.
- La estructura documental.

## 3. Versión de software

Este sprint no genera una versión funcional de la aplicación.

Por tanto, no se le asigna un número de versión de software.

Las versiones del backend y del frontend se identificarán cuando corresponda, utilizando un criterio de versionado que deberá establecerse durante el desarrollo.

## 4. Relación con Git

El historial de Git permitirá identificar los cambios realizados durante el desarrollo.

Los commits de AccessWay no deben confundirse con versiones oficiales de la aplicación.

Cuando se decida publicar una versión concreta, se podrá estudiar la utilización de etiquetas de Git.

## 5. Estado posterior

Tras el Sprint 0, el proyecto continúa con el estudio tecnológico, la preparación del entorno y la implementación progresiva del MVP.
